# Emmanuel Kokele

Papua New Guinean software engineer · Founder & Lead Developer, [Waghi Tech](https://waghitech.com).

I build full-stack web and mobile software at [Waghi Tech](https://waghitech.com) in Port Moresby: digital payments with [Waghi Pay](https://pay.waghitech.com), education systems including the [DBTI Online Registration](https://dbtionline.waghitech.com) platform (**Best in Technology Award, DBTI 2024** for the DBTI Online Registration and Payment System), and security tooling with [WaghiRecon](https://tools.waghitech.com). I also work in the public sector on scholarship administration systems and automation. Source code for these products is private; the links below are the live services and public case studies.
